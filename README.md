# 用数学看世界

> 从热点新闻里挑一个能用数学建模解决的问题，做成一道完整的题、一篇论文，
> 再把结论讲清楚。**数据与代码全部公开。**

## 这是个什么频道

每期做一件事：**把一条新闻里的数字，还原成一道能算的数学题。**

选题不看热度看**可算性**——能不能拿到公开数据、能不能建立可验证的模型、
结论能不能给出区间而不是一句断言。然后把全过程摊开：

* **论文**：完整的题面、建模、求解、灵敏度分析与**诚实性声明**；
* **代码**：可复现的求解脚本，不含任何绝对路径；
* **结果**：每个数字都落盘，论文里的数字都能追到 `results/`；
* **踩坑**：错误结论、走不通的路、被推翻的判断 —— 全部留档。

**三条硬规矩**：
1. **每个数字都要能溯源**；
2. **拿不到数据就换题**，绝不用「假设数据」硬撑；
3. **把失败也写下来** —— 失败与迭代比成功更有信息量。

## 每期简介

### [2026-W38](episodes/2026-W38/) · 物价只涨了 0.8%？——居民消费价格的结构分解与分组重构

**在问什么**　CPI 同比只涨 0.8%，为什么你的体感不是这样？把总指数拆成分项，再按自家消费结构重新加权。

**结论**　总涨幅低 ≠ 没涨价：涨得最猛的是每天都要买的东西；换一套权重，同一个 0.8% 会变成完全不同的体感。

**用到的方法**　结构分解 · 分组重构 · 权重敏感性

### [2026-W39](episodes/2026-W39/) · 每秒调一千次阻尼，为什么还是不如「主动」？——智能悬架与被动悬架的控制权限差异分析

**在问什么**　「每秒一千次阻尼调节」听着很猛，但对乘坐舒适性到底有多大用？建四分之一车模型，算出四类悬架的能力边界。

**结论**　决定隔振的是**力域**（能使多大劲），不是**响应速度**（调得多快）：力提高 10 倍改善一倍以上，带宽提高 10 倍只改善约 2%。所以「自适应路况」本身没有价值。

**用到的方法**　动力学建模 · 无源性约束 · 可达域扫描

### [2026-W40](episodes/2026-W40/) · 越来越热，也越来越涝？——高温与暴雨的联合极值风险

**在问什么**　高温和暴雨，会一起来吗？用 16 个城市、86 年的逐日数据，检验「极端事件会叠加」这个流行说法。

**结论**　数据不支持它：**越极端，越互相排斥**（99 分位风险倍数仅 0.32）。还发现**气温有上界、降水没有**——两类「破纪录」是相反的分布。北京 1940 年的「五十年一遇」，现已只相当于约 6 年一遇。

**用到的方法**　极值理论（GEV/GPD）· Copula · 非平稳检验

### [2026-W41](episodes/2026-W41/) · 一条新运河，能解开一个老堵点吗？——平陆运河通航后西江航运格局的分流效应与瓶颈转移

**在问什么**　平陆运河 2026 年 9 月通航了，货会走吗？用 15 期官方月度简报（长洲船闸 2025-08 ~ 2026-06）量化老瓶颈、预测分流、并检验新通道自己会不会堵。

**结论**　会分流，但幅度 **22%–45%**，不是全搬过去——真正的制约是**船东的转换惯性**（敏感性 ±90%），不是硬件（通道能力仅 ±18%）。新通道利用率只到 52%，**短期内瓶颈不会搬家**。另有一个先验假设被数据证伪：长洲拥堵与**水位无关**，主因是**检修停航**（排除检修期后相关性只剩 +0.078）。

**用到的方法**　排队论 · 多项 Logit（含转换摩擦）· 串联系统瓶颈律 · 敏感性分析与方向性判断

### [2026-W43](episodes/2026-W43/) · 老旧小区加装电梯：怎么分摊，才能谈成？

**在问什么**　给老楼加装电梯，政策在推、补贴在给、高层老人也确实需要——为什么还是谈不成？把 12 户的利益、民法典的表决门槛、一楼的采光损失一起写进模型，看哪种方案真能把可谈成率抬上去。

**结论**　**卡的不是「钱怎么分」，是「一楼的损失谁补」。**在 120 个参数组合上，**货币补偿把可谈成率从 16.7% 提到 80.8%**；而「调分摊比例」和「改设计降损」的提升**都是 0**。论文进一步证明了一个恒等式：$u_i = s_i[\text{总支付意愿}-\text{净造价}]$ ——每层按同一比例分享总剩余，**净收益的符号由总量决定、与分摊曲线无关**；且一层受益份额恒为 0 ⇒ **它必须有补偿，与它损失多小无关**。另一个反直觉点：**12 户里 4 户就能否决**（民法典 278 条的门槛是相对「参与者」而非全体）。

**用到的方法**　合作博弈（Shapley 值/核）· 讨价还价与外部选项 · 表决门槛的组合计数 · 参数敏感性（120 组）

### [2026-W44](episodes/2026-W44/) · 幼儿园关停：出生人口下降的传导，到最坏时刻了吗？

**在问什么**　2025 年全国幼儿园降到 23.19 万所，连续第四年减少、降幅还在扩大（-1.90% → -5.12% → -7.69% → -8.45%）；同期出生人口从 1786 万掉到 792 万。把这两条曲线接到一起，问三件事：需求还会掉多少、入园率能不能对冲、关停该怎么排顺序才公平。

**结论**　**最坏时刻还没到。** 用队列要素模型标定得队列在园率 0.9727（RMSE 65.12 万人），预测 2035 年在园幼儿 2311–2827 万人（较 2025 年 -12% ~ -28%），未来十年**还需净减 2.9–6.6 万所**。**入园率无法对冲**：毛入园率已 92.9%、队列在园率约 0.97，即使顶到理论上限 100% 也只能挽回 177 万人（+7.6%），而出生人口降幅是 55.7% —— 数量级上不可能。用「已兑现比例」量化传导进度：总落差 47.4%、已兑现 33.1%，即 **69.8%**，谷底约在 **2028 年**，届时所需幼儿园较 2025 年**再减 4.67 万所**。撤并规则本身就是政策抓手：不同策略的可达性代价相差 **23.2%**，且**「优先关在园幼儿最少的园」接近最优**（与贪心最优只差 1.0%），而**「优先关最偏远的园」最差**（+27.0%）—— 因为偏远园往往正是当地唯一的就近供给。收缩主要由民办园承担（2018–2025 民办在园 -50.3%、公办 -5.0%，弹性比 1.98 倍），但**「保本规模」反推失败**：任何纯规模阈值都造不出观测到的 1.91 倍退出率差异，主导因素是体制差异而非规模。

**用到的方法**　队列要素法 · 分布滞后 · 设施选址与多目标优化 · 撤并策略对比实验

### [2026-W45](episodes/2026-W45/) · 一颗老鼠屎能坏多少锅汤？——开源供应链蠕虫式扩散的图论建模

**在问什么**　2026 年 9 月 23 日，一个给 AI 应用做「长期记忆」的开源框架被投毒（npm 与 PyPI 同时中招）。手法换代了：不再靠「装完就跑」的安装脚本（已被默认禁用），而是把载荷挂进**本来就会运行的功能路径**，并偷走发布令牌 —— 拿到就能以你的名义发新版本，你维护的其他包跟着中招。这就是**蠕虫**。各方说「没有证据显示已扩散」，但**没证据和不会，是两件事**。于是把 20 个流行仓库的依赖闭包拼成一张真实的图，算清楚：投毒一颗，到底能坏多少锅汤。

**结论**　**投毒收益极不均匀，但驱动因素是「长尾无人问津」，不是「头部寡占」。** 在 **7830 个包 / 13496 条边**的图上，**77.5% 的包入度 ≤1**（最多只有一个包依赖它）、入度 ≥50 的只有 **6 个**（0.1%），而入度基尼只有 **0.380** —— 前 1% 的包也只占被依赖总量的 **14.4%**。**最反直觉的一条：被依赖最多 ≠ 最该加固。** 同样是挑 10 个包加固，按「被依赖最多」挑只能削减 **3.19%** 的期望受害量，按「阻断它能救下多少条依赖链」挑能削减 **32.38%** —— **差一个数量级**；原因是高被依赖的包多在**链路末端（叶子）**，堵住它只保护它自己。**最有行动价值的一条**：那次投毒「没有扩散」是**结构上可预期的** —— 被投毒的两个包根本不在闭包里（20 个仓库**0 个**依赖它）；**但若攻击者瞄准枢纽包，结论会反转**：入度最高的包在 p=0.2 时局部 R0 高达 **19.4**。此外，全图临界执行概率约 **0.58**，而**只有 4.65% 的包能「自我维持」** —— 平均值在这里会骗人。

**用到的方法**　有向图与度分布刻画 · 独立级联与传播阈值 · 局部 R0 与临界概率 · 加固预算的贪心优化（穷举验证达优 0.9935）

## 怎么读

**想直接看结论** → 进某期的 `paper/结论速览.md`（一页纸，所有数字都能追溯到 `results/`）。

**想跑代码**：
```bash
cd episodes/<期号>
pip install -r requirements.txt
python <该期 README 里写明的复现入口>
```

**想看踩过的坑** → 每期的 `_logs/踩坑.md`。

## 目录约定

```
episodes/<期号>/
  README.md            本期的说明（题目、复现入口、诚实性声明）
  requirements.txt     本期的复现依赖
  paper/               论文（Markdown）
  scripts/             可复现的求解代码
  results/             数值结果 + figs/ 插图
  data/来源清单.md      每个数据/参数的出处；含「被拒用的数字及理由」
  _logs/踩坑.md        本期踩过的坑与错误结论
```

## 环境

各期依赖见其 `requirements.txt`。共同要求 Python 3.10+；
`numpy / scipy / pandas / matplotlib` 为基本盘。
**视频配音不在复现路径内**（本地部署 TTS，需 GPU 与模型权重，未纳入仓库）。
