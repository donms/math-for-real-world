## 一、核心结论（三句话）

1. **最重要的一条**：
   **官方那个“大桥 -15.2%”既不是高估也不是低估，而是一个没有分解的口径。**
   分解模型给出恒等式 $\Delta_{分流}+\Delta_{诱增}\equiv 2.92$ 万辆/日
   => **两者各自的份额不可由现有数据识别**。
   用官方“日均引流 **1.64 万辆**”作硬下界，区间收紧为：
   **分流 [1.64, 2.92]、诱增 [0, 1.28] 万辆/日**。

2. **最反直觉的一条**：
   **瓶颈不是“隧道不够用”，而是“车没有更多地走隧道”。**
   高峰时大桥饱和度 **1.71（过饱和）**，隧道只有 **0.51**。
   限速 80 km/h 的能力代价仅约 **7%**，**不足以解释**隧道只分到 22%。

3. **最有行动价值的一条**：
   **靠价格推不动** —— 2020 年全国免收通行费（免收 **79/366 天 = 21.58%**）
   之后，收入归一化与 2019 年**偏差仅 0.06%**
   => **价格降幅 100% 没抬高长期需求** => 调价只能**重分配**，不能抑制需求。

## 三、四问结论（一句话版）

| 问 | 一句话 |
|---|---|
| **1** | 高峰大桥**过饱和**（1.71）；观测分配**不是均衡**（大桥成本高 43 min 却不转移）|
| **2** | 分流与诱增**不可完全识别**（和为 2.92 是恒等式）；用显式引流 1.64 万辆定出下界 |
| **3** | 7,696 辆/h **只能是通道合计**；隧道饱和度仅 0.51，**瓶颈是『车没走隧道』** |
| **4** | 桥隧同价**未使总时间最小**，但模型最优是**退化解**；需求对价格**不敏感** |

## 五、写内容时必须带上的诚实性声明

1. **2024–2025 的桥体流量是推断值**（公司改披露口径），引用须标注；
2. **只有中秋一个假期的观测** => 结论不能外推到平日/全年；
3. **分流与诱增的各自份额不可识别** => **不要写“诱增占 X%”**；
4. **观测分配不是均衡** => 定价结论只在“若路径成本可被感知”的前提下成立；
5. **本文三个建模错误**（元胞自动机一度完全静止、SO 违反理论、长度口径不可比）**如实报告** —— 这是加分项，不是减分项。
