## 三、**没有公布**的关键参数（这是"反推"的起点）

| 缺什么 | 后果 | 本文怎么处理 |
|---|---|---|
| **整车质量** | 冲量与加速度都差一个比例因子 | 取 **2 000 kg**（③ 自定），并声明它只影响绝对值不影响量级 |
| **坡道几何（半圆环还是四分之一圆）** | ★ 直接决定半径是 10.5 m 还是 21 m | **按半圆环**（顶点高度 = 直径）取 `R = 10.5 m`（② 反解），**并在边界里声明这是解读而非公布** |
| **坡道实际高度与圆心位置** | 同上 | 同上 |
| **飞跃水平距离** | 起跳角与初速不唯一 | 由画面量得 **22.8 m**（①）作为约束 |
| **落地相对高度** | 落地速度不唯一 | 按 HUD 与画面推算，偏保守 |
| **储气罐压力** | 冲量预算多一个自由度 | 由 `0.6 m³ / 250 kg / 293 K` 反解 **35.06 MPa**（②），并做敏感性 |
| **喷口喉部面积** | 单喷推力不唯一 | 由"总推力 > 80 kN / 10 个喷口"反解 |
| **单次喷射时长** | 控制律不可复现 | 采用 **PFM（一阶 sigma-delta）**，`t_min = 13.3 ms`（③） |
| **喷口的真实坐标** | 力矩与净力都受影响 | 由照片与报道估布点（③），并**声明具体坐标是推断** |

## 四、本地的原始素材

| 路径 | 是什么 | 怎么来的 |
|---|---|---|
| `data/frames/` | 演示视频的抽帧（含坡道、车、卡车特写） | 用 ffmpeg 从公开演示视频抽帧，逐帧量像素 |
| `data/hud/` | HUD 读数帧（高度、速度） | 同上，用于 21 m / 7.74 m / 0.81 s 的读数量取 |
| `data/jump/`、`data/jump2/` | 飞跃段抽帧与手工关键帧 | 同上，用于 22.8 m 排布量取 |
| `data/plume/` | 羽流帧 | 用于判断喷口位置与点火时序（仅作旁证） |
| `data/vid/` | 各阶段核对图 | 抽取结果的校验拼图 |
| `publish/视频/sim_demo1_3d.mp4` | **倒挂四段复刻仿真**（自带 HUD：t / z / 俯仰 / 滚转） | 本文 `scripts/sim_demo1_3d.py` 生成 |
| `publish/视频/sim_jump_3d.mp4` | **飞跃五车 3D 复刻仿真**（自带 HUD：t / 高度 / 绕纵轴滚转角） | 本文 `scripts/sim_anim3d_v3.py` 生成 |
