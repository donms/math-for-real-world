# 2026-W59 数据来源清单

## 主数据源

| 项 | 值 |
|---|---|
| 机构 | 中央气象台（NMC）台风网 |
| 端点 | `https://typhoon.nmc.cn/weatherservice/typhoon/jsons/list_2026` / `view_<id>` |
| 协议 | 公开网页接口，**免密钥**；返回 JSONP，需剥壳 |
| 抓取时间 | 2026-10-30 22:15 |
| 样本 | **31 个命名台风**，实况点 1927 个，预报点 12255 个 |

## 口径

- **实况**：逐点轨迹，时间戳为北京时间 `YYYYMMDDHHMM`，经纬度为十进制度；
- **预报**：每个实况点附当时发布的预报，字段 `[提前量, 起报时, 经度, 纬度, 气压, 风速, 机构, 等级]`；
- **提前量**：6/12/18/24/36/48/60/72/96/120 h；
- **机构**：仅 `BABJ`（中央气象台）。

## 三条限制（必须随结论出现）

1. **只有 2026 季带预报存档** —— 2019–2025 抽查 28 个台风，含预报 0 个
   ⇒ 做不了跨年"预报进步"曲线；
2. **只有 BABJ 一个机构** ⇒ 不做机构对比；
3. **实况分辨率 6 h**（个别 3 h）⇒ 配对必须声明匹配规则与容差。

## 复现

```powershell
python scripts/fetch_typhoon.py --year 2026
```
