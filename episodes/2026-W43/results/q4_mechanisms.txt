  Q3  三类手段的敏感性：什么最能提高『谈成』的概率
========================================================================================================

  基准：造价 500,000、补贴率 40%、低层损失 1层/2层 = 1,500/1,500 元每户

========================================================================================================
  【1】先验证 Q2 的结构性结论：分摊与补偿**不改变总剩余**
========================================================================================================
    κ=1.5 时：净造价 300,000，WTP 450,000，总剩余 150,000

    改变分摊曲线（γ 从 1.0 扫到 3.0），看总剩余是否变化：
       γ           总剩余     P3可谈成         2层净收益         6层净收益
  ----------------------------------------------------------
    1.00       150,000         否        10,000        50,000
    1.35       150,000         否         6,456        56,694
    2.00       150,000         否         2,727        68,182
    2.50       150,000         否         1,362        76,128
    3.00       150,000         否           667        83,333

    ⇒ 总剩余**恒为 150,000**，与 γ 无关 ✅（验证 Q2）
      但层间净收益**差异巨大**（2 层 vs 6 层）⇒ 分摊只决定**分配**。

    再加补偿（每户 +2000 元，内部转移）：
          补偿           总剩余     P3可谈成        一层缺口        二层缺口
  ----------------------------------------------------------
           0       150,000         否       1,500           0
       1,000       150,000         否       1,500           0
       2,000       150,000         是           0           0
       5,000       150,000         是           0           0

    ⇒ 总剩余**仍恒为 150,000** ⇒ **补偿也不创造价值**，
      只把剩余在层间搬动（缺口随之变化）。

========================================================================================================
  【2】★ 题面指定的反事实：『损失降 30%』 vs 『多补 2 万元』
========================================================================================================
    基准损失：一层 1,500、二层 1,500 元每户
    A 方案：改设计使损失下降 30%（L → 1,050）
    B 方案：每户多加补偿 20,000 元（内部转移）

  方案                                   总剩余    P1    P2    P3        最大缺口
  ----------------------------------------------------------------------------
  基准（不动）                           150,000     ✓     ✗     ✗       1,500
  A 损失降 30%                        150,000     ✓     ✗     ✗       1,050
  B 每户多补 2 万                       150,000     ✓     ✓     ✓           0
  A+B 同时                           150,000     ✓     ✓     ✓           0

  ⇒ **在总剩余为正时，两个方案都能达成**（本项目基准下剩余充裕）。
     ⇒ 要看清差别，必须**把 κ 压到临界附近**（剩余很小）—— 见下一节。

========================================================================================================
  【3b】★ 补贴有效吗？—— 取决于 WTP 是否随净造价缩放
========================================================================================================
    【模型 1】WTP = κ·(C−s)（本脚本主模型）
      ⇒ 可行性条件可解析化为
           (κ−1)(C−s) ≥ 需补偿额
        而需补偿额 = L1 + max(0, L2 − s2·(κ−1)(C−s))
        ⇒ **补贴率 s 在两侧同时出现并抵消** ⇒ 补贴无效。
      ⚠️ 这是**模型假设的产物**：它假定了'业主愿付随净造价等比缩放'。

    【模型 2】WTP 外生固定（不随补贴变）
      ⇒ 补贴直接降低净造价 ⇒ 可行性单调改善。

       补贴率         净造价       剩余(模1)   P3(模1)       剩余(模2)   P3(模2)
  --------------------------------------------------------------------
       0.0     500,000      250,000        ✗      -50,000        ✗
       0.2     400,000      200,000        ✗       50,000        ✓
       0.4     300,000      150,000        ✗      150,000        ✓
       0.6     200,000      100,000        ✗      250,000        ✓

  ⇒ **两种模型给出相反结论** ⇒ 『补贴是否有效』在本模型中
     **不可识别**，取决于一个无法从数据验证的假设。
     必须在论文中如实声明（见诚实性声明）。
