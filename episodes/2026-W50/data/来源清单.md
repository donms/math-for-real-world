## 二、[!] 数据性质与缺陷（**必须随结论出现**）

1. ★★ **覆盖率不完整** —— 网络超时导致
   * 依赖图 **58.8%**（86924 / 147850）；
   * 声明级 **47.5%**（41272 / 86924）。
   => **所有规模类数字只报下限。**

2. **API 的文件数统计曾被截断** —— 首次用 git trees API 数出
   `lean/` 有 **60209** 个文件，而 tarball 实测是 **147850** 个。
   => **API 的 `truncated=true` 意味着数字不可信**，已改用 tarball 实测值。

3. **未解析 `namespace`** —— 记录的是**局部名**，不是全限定名。

4. **只抽 `theorem`/`lemma`** —— `def`/`structure`/`instance` 未计入，
   声明数**低估**。

5. **依赖边只用 `import`** —— 不反映 tactic 内部的实际引用
   （`exact`/`simpa using`/`rw [...]`）。

6. ★★ **本期不评判结果真伪** —— 真伪需领域专家阅读源码。
