# 用数学看世界

> 从热点新闻里挑一个能用数学建模解决的问题，做成一道完整的题、一篇论文，
> 再把结论讲清楚。**数据和代码全部公开。**

本仓库对应 **2026-W53** 期：**「周一早高峰最堵」是假的 —— 1.13 亿条车速记录里的观测窗口偏倚**

## 结构

```
episodes/2026-W53/
  paper/               论文（Markdown）
  scripts/             可复现的求解代码
  results/             数值结果 + figs/ 插图
  data/来源清单.md      每个数据/参数的出处；含「被拒用的数字及理由」
  _logs/踩坑.md        本期踩过的坑与错误结论
```

## 复现

```bash
pip install -r requirements.txt
cd episodes/2026-W53
python scripts/q1_monday.py
```

每个脚本把结果写到 `results/` 并打印关键中间量。
**脚本不含任何绝对路径。**

> [!] **原始数据不在本仓库里**（`data/raw/`）。
> 它们可由公开 API 重新取到，且体积很大（本期约 848 MB）——
> 进包会让仓库膨胀近 20 倍。
>
> **跑分析脚本前请先取数**（约 35 分钟，无需任何密钥）：
>
> ```bash
> cd episodes/2026-W53
> python scripts/fetch_traffic.py --weeks 18 --anchor 2026-09-07
> ```
>
> `--anchor` 必须是**周一**（脚本以周一为一周之始）；
> 本期 18 周是 **2026-05-11 … 2026-09-07**。
> 完成后 `data/raw/` 会有 36 个文件（`speed_*.jsonl` 与 `mta_*.jsonl` 各 18 个）。
>
> 完成后再跑 `python scripts/q1_monday.py`。
>
> **只想看结论的话不需要取数** ——
> `results/*.json` 与 `paper/` 里已落盘全部数字与图表。
>
> 缺失时的报错是**明确的**（会打印上面这条命令），不会静默出错。


## 本期的定位

见 `episodes/2026-W53/paper/论文.md` 的开头与「模型的评价与推广」一节：
论文中明确写有模型假设、适用范围与**诚实性声明**。

## 三条硬规矩

1. **每个数字都要能溯源**——论文里的每个数字都必须能在 `results/` 找到落盘出处；
2. **拿不到数据就换题**，绝不用「假设数据」硬撑；
3. **把失败也写下来**——错误结论、走不通的路、被推翻的判断，全部留档在 `_logs/踩坑.md`。

## 诚实性声明

* 本仓库内容为**数学建模练习与技术分析**，**不构成任何政策或决策建议**。
* 凡涉及参数不确定性的结论，均给出**灵敏度分析**；
  只用文献典型值而未获实测确认的结论，只给**排序与区间**，不给单点断言。
* 失败尝试与错误结论**如实留档**。
