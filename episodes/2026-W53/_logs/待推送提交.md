**实测**：`rebase --onto` 之后，
`episodes/2026-W53/` 的**文件数为 0**、`git ls-files` 也为 0

> **教训**：`git rebase --onto A B main` 会**把 B..main 的改动从工作区撤出**。
> 若想「保留文件但不出现在历史里」，必须**另做一步**：
> `git checkout w53-pending -- episodes/2026-W53`
> （此时文件是**未跟踪**状态，不会进历史）。

## 怎么恢复

```bash
cd <LOCAL_PATH>

# 方式一：恢复成一次提交（推荐）
git cherry-pick w53-pending        # 等价于 cherry-pick 3972894

# 方式二：只恢复文件、不要提交
git checkout w53-pending -- episodes/2026-W53

# 确认
git log --oneline -3
git status --short
```
