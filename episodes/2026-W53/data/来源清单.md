## 三、★★ 被**拒用**的数字及理由

| # | 数字 | 曾得出 | 为什么拒用 |
|---|---|---|---|
| **1** | **2026-09-01 的"中位车速 6.83 mph"** | 曾据此判断该日是"极端拥堵日，只有平常的 1/5" | ★ **那是原始记录的中位数，而 `speed = 0` 占 29.76% ⇒ 0 值一多，中位数被拖到 0 附近。6.83 根本不是车速。** 该日**日均速为 32.19 mph**，比中位日（34.57）只慢 **7%**，**甚至不在最差 10 个工作日里** |
| **2** | **"周一 vs 周二 = −0.210 mph，p = 0.0002"** | 曾据此认为"周一效应存在" | ★ **该结果来自"用固定分母 36000 算覆盖率"的口径**。5 月只有 101 条路段，固定分母下覆盖率上限 80.8% ⇒「门槛 ≥ 90%」**等价于"只用 6 月以后的数据"**，**与季节完全混淆**。改用归一化分母后为 **−0.001，p = 0.736** |
| **3** | **"14 行/时间戳 ⇒ 每 103 分钟一批"** | 曾据此怀疑"分不出早高峰、选题不成立" | ★ **`data_as_of` 是每条记录各自的采集时刻，不是批次号。** 各路段采集时刻互相错开 ⇒ 唯一时间戳数远多于批次数。拉单路段整天核对：**288 点、中位间隔 5.0 分钟** |
| **4** | **含 0 值的早高峰均速 24.3 mph** | 早期体检结果 | 保留作**对照**，但**不作为主口径**：`speed = 0` 按"无读数"剔除后为 **33.4 mph**（差 9 mph）|
| **5** | **匹配数恒为 0 的配对结果** | `q1` 第一版报"无配对样本" | **键切片写错维度**（`k[1:]` 切掉的是"星期"而非"周"）⇒ 周一键与周二键永远不可能相等。**已修** |
| **6** | **"周一在极端日里过度出现"** | 直觉假设 | **数据否定**：最差 20% 工作日里周一只占 **6.2%**（基准 20%），三个分位全部不显著 |

## 五、SoQL 查询要点（**全部实测踩出来的**）

```text
① $where 的时间要带引号，且必须显式卡上下界
   （全表含 1930-12-09 的脏记录）：
   $where=data_as_of>'2026-09-07T00:00:00' AND data_as_of<'2026-09-14T00:00:00'

② 日期函数可用：date_trunc_ymd / date_extract_hh / date_extract_dow

③ ★★ 服务端**绝不能**对 speed 做数值聚合 —— 它是文本列：
     avg(speed)                  -> Type mismatch for avg, is text
     avg(cast(speed as double))  -> 语法错误
     avg(speed::double)          -> Type mismatch for cast$double
     to_number(speed)            -> No such function
   ⇒ 必须取原始行，本地转 float 再算

④ ★ 全表 $group 会超时（1.1 亿行）⇒ 必须先用 $where 卡时间窗（按周切片）

⑤ 分页用 $offset；单页 $limit 最大 50000

⑥ URL 里的空格必须编码；但 `$` `=` `&` `'` `(` `)` `,` **必须留在 safe 里**，
   否则 Socrata 报 "Unrecognized arguments"

⑦ 批量取数会遇到 HTTP 403 限流 ⇒ 冷却 90 秒后重试即可（实测成功）
```

## 六、数据边界（**必须随结论出现**）

1. **`speed = 0` 占 29.76%**，本期按"无读数"剔除。
   **该判断无法从数据内部证实**；已做敏感性分析：
   剔除与保留两种口径下**周一效应的结论不变**，
   但工作日/周末效应的**量级**会变（−6.534 对 −4.528）。
2. **两套数据空间不重叠**（车速 = 101 条普通路段；流量 = 桥梁与隧道）
   ⇒ 只做**同日同期形态对照**，**不能逐路段配对、不能作因果陈述**。
3. **仅 101 条路段、18 周**，且**不覆盖冬季**。
4. **未引入天气与事故数据** ⇒ 单周极端值只能当噪声处理。
5. **"通勤窗口 = 7 到 9 时"未经敏感性检验**（本文未做，列为缺口）。
