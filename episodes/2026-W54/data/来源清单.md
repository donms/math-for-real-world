### 1.6 ★★ 核心发现：**物业费本身不够**

```
物业费收入   1 432 894.24 元/月
支出         1 576 960.74 元/月
────────────────────────────
物业费单项   −144 066.50 元/月   （年 −172.9 万元）
停车费       +148 500.00 元/月
────────────────────────────
账面          +4 433.50 元/月
```

**单位口径**：

| 量 | 值 |
|---|---|
| 单位成本 | **5.5863 元/㎡·月** |
| 单位物业费收入 | 5.0760 元/㎡·月 |
| 单位总收入（含停车）| 5.6112 元/㎡·月 |
| **单位缺口**（成本 − 住宅名义单价 4.91）| **+0.6763 元/㎡·月** |
| **保本单价** | **4.894 元/㎡·月** ⇒ **现行 4.91 仅高出 0.016 元（0.3%）** |

**⇒ 结论：4.91 元已经**贴在保本线上**，物业「不降价」有算术依据。**
**而业委会诉求 2.398 比保本线低 2.496 元（低 51%）。**

### 1.7 三处残留不一致（**不阻塞，但必须如实记录**）

| # | 现象 | 实测 |
|---|---|---|
| **①** | **税金基数与费率不符** | 表给 96 290.49。按基数 1 284 097.92 × 6.72% = **86 291.38**（差 9 999.11）；而**物业费收入 1 432 894.24 × 6.72% = 96 290.49**（精确吻合）⇒ **税金按收入计，管理费按成本基数计，两者基数不同** |
| **②** | **支出表「合计」行与 1–8 项之和差 3 500** | 1–8 项之和 = 1 287 597.92；用户核对的合计行 = 1 284 097.92 ⇒ 差 **3 500**（恰等于"固定资产折旧"）⇒ 疑该行已含在合计中或重复列示 |
| **③** | **利润差 2 600 元/月** | 1 583 994.24 − 1 576 960.74 = **7 033.50**，表给 **4 433.50** ⇒ 差 **2 600 元/月（年 31 200）**。**文章说「这还没摊总部管理费、品牌费」** ⇒ **推测这 2 600 就是表外的总部/品牌费**，但**未获证实** ⇒ 论文里只写"存在 2 600 元/月的未解释差额，作者称系总部管理费与品牌费" |

## 四、用户提出的新变量（**本期的核心假说**）

> 用户原话：
> "这两年新拍的地很多都是很小的地块，**有的只有 100-200 户**，
> 以后这样的物业争端会不会越来越多。"

**待检验的假说**：
> **小区户数越小 ⇒ 单位面积分摊的固定成本越高 ⇒ 物业费覆盖不了 ⇒ 撤场与争端越多。**

**需要的数据**：① 近年成交地块的**户数/建面**分布；② 物业成本的**固定/可变**拆分。
**② 可以从主案例的成本结构估计**（人员、秩序维护、行政办公含固定成分）。

### 6.2 ★★ 真正的机制（从页面 JS 里读出来的）

```javascript
/* 摘自 tdsc_gettdcrinfo.action 返回页面的内联 JS */
function getPageList(start, limit) {
  var Param = {};
  Param.start   = start;      // ★ 页码（从 1 开始）
  Param.limit   = limit;      // 每页条数（实测 18）
  Param.xzqhdm  = $("#xzqhdm").val();      // 区划码
  Param.lx      = $("#lx").val();          // 类型
  Param.affiche_no  = $("#affiche_no1").val();     // 公告编号（模糊）
  Param.remise_type = $("#remise_type1").val();    // 出让方式
  Param.starttime   = $("#starttime1").val();      // 起始时间
  Param.endtime     = $("#endtime1").val();        // 结束时间
  $.post("tdsc_getTdcrList.action", Param, function(resp) {
      var result = eval("(" + resp + ")");
      $("#tdcrTableHtml").html(result.tableHtml);   // 表格 HTML
      $("#tdcrPagingHtml").html(result.pageHtml);   // 分页 HTML
  });
}
```

**⇒ 分页是 `POST tdsc_getTdcrList.action`，参数为 `start` + `limit`。**
