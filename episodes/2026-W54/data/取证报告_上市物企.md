**取证时间**：2026-10（当前时点）。2025年年度报告已于2026年3-4月披露；2026年中期报告已于2026年8-9月披露。
**覆盖范围**：港股物业股为主（财务数据覆盖 45 家），A股仅能取到行业汇总口径（见 §4 缺口清单）。
**环境限制说明**：本机 PowerShell **无外网能力**（所有 `Invoke-WebRequest` 均失败），全部数据经 `web_fetch` / `web_search` 获取。`hkexnews.hk` 的 PDF 正文无法直接抓取（搜索页为 JS 渲染），故年报数据主要通过**财经媒体逐字转载的业绩公告/管理层讨论与分析**获取，已在来源列标注类型。

## 0. 数据来源类型标注约定

| 标记 | 含义 |
|---|---|
| `[API]` | 东方财富数据中心 JSON 接口原始字段（结构化，等同财报数值） |
| `[年报原文]` | 媒体**逐字转载**的年报/业绩公告正文，或公司官网发布 |
| `[业绩会]` | 业绩发布会管理层答问实录（观点/乐居/澎湃/第一财经等现场记录） |
| `[研报转述]` | 第三方研究机构（中指研究院、克而瑞物管、中物智库、观点指数）测算或统计 |
| `[媒体转述]` | 记者报道中的二手陈述 |
| `[推算]` | 本报告由已披露数据计算得出（**非披露值**，已标注算式） |

> 东方财富接口模板（可复现）：
> `https://datacenter-web.eastmoney.com/api/data/v1/get?reportName=RPT_HKF10_FN_MAININDICATOR&columns=ALL&filter=(SECUCODE="06098.HK")&pageSize=8&pageNumber=1&sortTypes=-1&sortColumns=STD_REPORT_DATE&source=F10&client=PC`

### 2.1 关键发现

1. **单项目平均在管面积高度收敛在 13–15 万㎡ 区间**。四家严格口径企业（建发14.81、绿城14.81、碧桂园12.94、雅生活13.02）极差仅 1.9 万㎡。这为建模提供了**可靠的行业标度参数**：一个"典型住宅物业项目"约 13–15 万㎡。
2. **规模越大，单项目平均面积反而越小**：碧桂园服务（最大）12.94万㎡ < 绿城/建发 14.81万㎡。与碧桂园服务大量项目位于三四线、单盘体量小、项目极度碎片化一致——**这直接支撑"项目越小越难赚钱"的假说**。
3. **万物云住宅单项目年收入仅 451 万元，对应分部毛利率 11.7%**（全公司毛利率 12.23%，已是头部最低）。若按住宅毛利率11.7%反推：单项目年毛利 ≈ 451.2 × 11.7% = **52.8 万元/项目/年**。以住宅项目平均 13–15 万㎡、约 1000–1500 户估算，**单项目年毛利仅够支付 2–3 名基层员工年薪**——项目管理与职能费用摊薄后极易转负。这是"小项目不赚钱"最强的量化证据链。

### 3.1 ★★★★ 最直接的阈值型论断（可直接写进模型约束）

> **「对于单个物业项目而言，85%的收缴率是盈亏平衡线，也是项目可持续运营的核心阈值，若收缴率低于60%则大概率面临深度亏损乃至停摆，大部分企业只能选择撤场。」**

> **「2025年，其所在公司对所有在管项目和合同项目盘点和审核后，要求对两类项目启动退出应急机制：第一类为项目连续两年收支无法平衡；第二类为项目连续两个缴费期收缴率低于50%。触及任何一条红线，项目即启动退出程序。」**
> —— 某物业公司负责人（经济观察报采访）

> **「净利润2.5亿元以下的45家中小企业毛利率均值达21.84%，反而高于净利润5亿元以上8家头部企业的19.13%，但其净利率均值仅6.64%，明显低于头部企业的9.14%。这说明中小企业利润承压的症结并不在基础业务的盈利空间，而在于规模不足导致的费用摊薄能力弱、减值计提压力与管理成本刚性，'高毛利、低净利'成为中小物企的典型困境。」**

## 5. 给建模的直接建议（基于以上取证）

1. **单项目规模标度**：取 **13–15 万㎡/项目**（严格口径4家样本：12.94 / 13.02 / 14.81 / 14.81）。
2. **单项目盈利方程的核心参数**：
   - 收缴率盈亏平衡线 = **85%**（中指彭雨，`[研报转述]`）
   - 深度亏损线 = **收缴率 < 60%**
   - 强制退出红线 = **连续两期收缴率 < 50%** 或 **连续两年收支不平衡**（某物企内部制度）
   - 住宅毛利率基准 = **11.7%**（万物云，唯一实测值）
   - 基础物业服务合理毛利区间 = **15%–20%**（永升服务总裁）
3. **最强的"小项目不赚钱"证据链**：万物云住宅项目 4638 个 → 单项目年住宅收入 451.2 万元 → × 住宅毛利率 11.7% = **单项目年毛利 52.8 万元**（[推算]）。这一量级无法覆盖项目管理与职能费用摊薄，与中指"中小企业高毛利(21.84%)但低净利(6.64%)，症结在规模不足导致费用摊薄能力弱"的结论完全吻合。
4. **可用的时间序列锚点**：收缴率 2021年94.23% → 2025年87.32%（百强口径），**连续5年单调下降，累计-6.91pct**，可直接作为模型的外生趋势项。
