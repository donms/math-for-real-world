# 用数学看世界

> 从热点新闻里挑一个能用数学建模解决的问题，做成一道完整的题、一篇论文，
> 再把结论讲清楚。**数据和代码全部公开。**

本仓库对应 **2026-W40** 期：**越来越热，也越来越涝？——高温与暴雨的联合极值风险**

## 结构

```
episodes/2026-W40/
  paper/               论文（Markdown）
  scripts/             可复现的求解代码
  results/             数值结果 + figs/ 插图
  data/来源清单.md      每个数据/参数的出处；含「被拒用的数字及理由」
  data/城市清单.json    分析脚本的输入（城市经纬度与分组）
  _logs/踩坑.md        本期踩过的坑与错误结论
```

## 复现

```bash
pip install -r requirements.txt
cd episodes/2026-W40
python scripts/q1_marginal.py
```

每个脚本把结果写到 `results/` 并打印关键中间量。
**脚本不含任何绝对路径**，clone 后可直接运行。

## 本期的定位

见 `episodes/2026-W40/paper/论文.md` 的开头与「模型的评价与推广」一节：
论文中明确写有模型假设、适用范围与**诚实性声明**。

## 三条硬规矩

1. **每个数字都要能溯源**——论文里的每个数字都必须能在 `results/` 找到落盘出处；
2. **拿不到数据就换题**，绝不用「假设数据」硬撑；
3. **把失败也写下来**——错误结论、走不通的路、被推翻的判断，全部留档在 `_logs/踩坑.md`。

## 诚实性声明

* 本仓库内容为**数学建模练习与技术分析**，**不构成任何政策或决策建议**。
* 凡涉及参数不确定性的结论，均给出**灵敏度分析**；
  只用文献典型值而未获实测确认的结论，只给**排序与区间**，不给单点断言。
* 失败尝试与错误结论**如实留档**。

* **数据来自再分析/网格产品，不是站点实测。** 经与公开气象报道比对：
  气温吻合良好（±0.5℃ 内），但**极端降水被显著平滑**
  （恩平单日实测 597.7 mm，网格仅 108.7 mm，约 18%）。
  故本仓库**不给降水绝对量的结论**，只做相对比较与趋势分析。
* 本文给出的是**气候风险**，不是灾害损失风险——二者之间还差一个「暴露度」。
